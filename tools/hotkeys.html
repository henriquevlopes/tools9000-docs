Hotkeys

Every key Tools9000 uses, in one table.

What it does

Tools9000 gives keys to its tools when you install it. This page lists them all. Where a key had a Max action before, that action is taken off the key so the two do not fight (two actions on one key in one place and neither runs).

How to use it

Press the key in a viewport, or in the window named in the table. You can change any key in Max under Customize / Customize User Interface / Keyboard, in the category "9000 Toolkit".

Max actions that lose their key: Disable Viewport (Ctrl+Shift+D), Save File (Ctrl+S), Align (Alt+A), Lock (Space), Sub-object Selection Toggle (Ctrl+B), Select All on Ctrl+A (it moves to A), and on 3 the Border level in the poly modes.

Good to know

  • Pie keys: hold the key, flick toward a button and let go.
  • A guest install used on another person's PC leaves keys they already use alone, and skips P, U and O.
  • The Alt+S, Alt+A, Alt+R, Alt+Z, Space, Ctrl+B and P / U / O tools are described on their own pages.
