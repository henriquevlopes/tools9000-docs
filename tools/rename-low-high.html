Rename Low / High

Name a low poly and its high poly parts in one go, ready for baking.

What it does

Select one low poly object and its high poly parts, then run the tool. The low becomes Body_low and the highs become Body_high, Body_high1, Body_high2 and so on, where Body is the low's name without its old suffix. Every high gets its own name, so other programs do not rename them on import.

How to use it

  1. Select the low poly and all its high poly parts.
  2. Press Alt+R (or run Rename Low / High from the 9000 Toolkit category).
  3. If something is wrong with the selection, a message box says what.

Options

There is nothing to set. The tool decides which object is the low like this:

  • An object on a layer named like a low poly layer (Low, LP, Low Poly and similar, or inside one) is always the low.
  • An object on a high poly layer (High, HP and similar) is always a high.
  • Otherwise the object with the fewest polygons is the low.

Good to know

  • Names are made safe for other programs such as Maya: spaces and symbols become _.
  • If another pair already uses the name, the new pair becomes Body_01_low / Body_01_high, then _02 and so on.
  • It is one undo step.
