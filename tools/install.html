Installation and setup

Drop one file on a viewport, tick the tools you want and restart Max.

What it does

The installer (Tools9000_Install.mzp) opens a setup dialog. You tick the tools you want and the hotkeys to go with them. Only the ticked tools are installed. Tools9000 is made for 3ds Max 2024 for now.

How to use it

  1. Start 3ds Max 2024.
  2. Drag Tools9000_Install.mzp onto a viewport.
  3. On the left, tick the tools you want. They are grouped as Pies, Modelling, UVs and Scene. All and None tick or clear everything.
  4. On the right, tick the hotkeys you want. A key you already use for something of your own starts unticked, with a note saying what it does now. Tick it only if you want to hand it over.
  5. If the UV toolbar is ticked and numpy is missing, a checkbox offers to download it. Pack, Unwrap and Optimize need it.
  6. Press Install, then restart Max when the dialog says so.

Options

WhereWhat you find
9000 Toolkit categoryEvery installed tool is a macro in Customize > Customize User Interface (Toolbars, Quads, Menus, Hotkey Editor), category 9000 Toolkit. You can bind any of them to a key or put it on a toolbar.
Right-click (quad) menuSome tools add an item right after Max's own: Knife Project after Cut, Inset 9000 after Inset, De-chamfer after Chamfer, Extend Borders after Extrude, Triangulate after Convert To, and Check N-gons after Rebuild Mesh. Max's own items stay.
Scripts part of the quad menuSeveral script-style tools sit here, for example Rebuild Mesh, Mirror and SplinePatch.
HotkeysThe right-hand list of the setup dialog. Tab, Shift+E, Ctrl+Shift+D and Ctrl+S open the pies, 3 is Clean Up, X is Remover, M is Merge, and so on.

Good to know

  • Run the installer again any time. It shows what is installed; ticking adds a tool and unticking removes it, with its macros and hotkeys.
  • If you untick a hotkey you had handed over, your own binding is put back.
  • Restart Max after installing tools that bring a plugin (Mirror, LoopTools, Spiral). Max keeps loaded plugins locked, so they appear after a restart.
  • Only Max 2024 is supported for now; other versions are planned later.
