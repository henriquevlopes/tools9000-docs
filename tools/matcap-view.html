Matcap View

A clay-style look for the active viewport. One click on, one click off.

What it does

Matcap View shows every object in the active viewport lit by a matcap picture, whatever its material. It is a display setting only: your scene and materials are not changed. It is handy for judging shape while modelling.

How to use it

  1. Click into the viewport you want.
  2. Run Matcap View (macro in the 9000 Toolkit category; it can sit on a toolbar as a button that shows when it is on).
  3. Run it again to turn it off. The viewport goes back to its earlier settings.

Options

ActionWhat it does
ClickTurns Matcap View on or off for the active viewport.
Shift+clickOpens a file dialog to choose the matcap picture (png, jpg, tga, bmp, tif).
Ctrl+clickSwitches to the next picture in the same folder.

Good to know

  • Each viewport remembers its own settings. While it is on, the viewport switches to the Performance preset with progressive rendering off, and both go back when you turn it off.
  • The highlight stays put in a wide perspective view.
  • If the chosen picture goes missing, the picture that comes with the tool is used.
  • A short message at the top of the viewport names the picture you chose.
  • It replaces the older SuperClayMode script and keeps its toolbar button working.
